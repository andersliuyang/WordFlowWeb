## 1. 项目概述与核心架构 (Overview & Architecture)

**WordFlow (字.迷)** 是一款基于 Web 技术构建的 3D 消除填字游戏。项目采用**运行时零网络请求（Zero-Network-at-Runtime）**架构：所有 3D 视觉、字符纹理、音效、词典与关卡数据均随应用一次交付，运行时不再发起任何 HTTP 请求，可部署为单文件静态网页。

### 1.1 核心技术选型

| 维度 | 选型 | 说明 |
|---|---|---|
| 宿主环境 | 单文件 HTML5 Web 应用 | 构建产物为单个 `index.html`，可部署于 CDN / Vercel / GitHub Pages / 本地双击 |
| 3D 引擎 | Three.js (WebGL) | 场景、立方体网格、相机、Raycaster 拾取；构建期内联，不走 CDN |
| 纹理生成 | Canvas 2D API | 离屏绘制字符与状态样式，生成 `CanvasTexture` |
| 音频引擎 | Web Audio API | 振荡器 + 包络合成全部音效与 BGM |
| 数据 | 内嵌 JSON / JS 模块 | AI 预生成关卡 + 词典，构建时打入单文件 |
| 构建 | Vite + `vite-plugin-singlefile` | 打包并内联为单 HTML |
| 存储 | localStorage | 进度 / 金币 / 设置 |

### 1.2 术语表 (Glossary)

| 术语 | 含义 |
|---|---|
| 方块 / Tile | 棋盘上一格，含 1 个字符，可为普通或障碍类型 |
| 棋盘 / Board | `grid_dim {x, y}` 定义的二维网格 |
| 目标词 / Target Word | 本关需要拼出并消除的词组 |
| 彩蛋词 / Bonus Word | 合法但非目标的词，存入额外词汇槽 |
| 路径 / Path | 玩家一次选取的相邻方块有序序列 |
| 步 / Move | 一次成功消除一个目标词（见 2.6） |
| 重力 / Gravity | 某列方块消除后，其上方方块沿列下落补位 |

## 2. 核心玩法规则详表 (Gameplay Rules)

> 本章为 v7.0 新增，用于消除 v6.0 的核心矛盾。**已确认采用模型 A：连线消除。**

### 2.1 棋盘与 3D 呈现

- 棋盘为**单层二维网格**，`grid_dim.x` 列、`grid_dim.y` 行，每格一个 `BoxGeometry` 立方体。
- 逻辑坐标原点 `(0,0)` 位于左上；`x` 向右递增，`y` 向下递增。
- 渲染时：`worldX = (x - (cols-1)/2) * spacing`，`worldZ = (y - (rows-1)/2) * spacing`，`worldY = 0`。
- 相机为**固定透视相机**，约 30°~40° 俯角正对棋盘中心；**禁止旋转/缩放（已确认）**。
- 方块之间留 `gap`，可带轻微悬浮呼吸动画。

### 2.2 选取与提交

1. `pointerdown` 命中方块 → 成为路径起点，播放点击音，方块抬升/高亮。
2. `pointermove` 经过的方块：若与**路径末位**在 8 邻域内相邻，且未被本路径选中，则追加；否则忽略。
3. `pointerup` → 立即提交整个路径。
4. 备选操作：单击逐格累积（tap 模式），再次点击路径末位方块可撤销一格。
5. 路径约束：**8 方向相邻、不可跳格、不可重复（已确认）**。

### 2.3 字符序列与校验优先级

- 将路径方块字符按顺序拼接为字符串 `s`（可选包含其反转 `reverse(s)`）。
- 校验顺序：
  1. `s`（或反转）命中某个**未完成目标词** → 成功消除。
  2. `s`（或反转）命中 `bonus_dictionary` → 存入额外词汇槽。
  3. 否则 → 失败反馈（路径方块抖动 + 低沉音效），清除选中。
- ✅ 已确认：**允许反向匹配**。`reverse(s)` 与 `s` 等价参与校验（路径「水山」可命中「山水」）。

### 2.4 消除与重力

- 命中的目标词方块按障碍规则处理（见 3.2）。
- 消除产生空位后，**每一列**内其上方的方块整体下落，填补空位；列顶留空，**不生成新方块（已确认）**，棋盘总量单调递减，保证可通关。
- 下落为 Tween 平滑动画（默认 180ms，`easeOutCubic`），全部落位后检查级联（2.5）。

### 2.5 级联与连击 (Combo)

- **时间连击**：两次成功消除间隔 ≤ 3s，则 `combo += 1`；超过 3s 重置为 0。
- **级联消除**：重力落位后，若棋盘上自动出现一个完整未完成目标词的相邻路径，则**自动消除**该词，`combo += 1`（可链式）。
- 表现：每级 combo 播放递升和弦（音高随 combo 提升）并触发 3D 粒子爆炸；得分/金币倍率 = `1 + 0.2 * combo`。

### 2.6 胜负与步数

- **通关**：所有目标词被消除。
- **失败**：`move_limit` 步数耗尽，或炸弹爆炸（见 3.2）。
- **一步的定义**：一次**成功消除目标词**计 1 步；失败提交不计步（已确认）。
- `move_limit` 仅 `hard` 关卡存在（默认 `null` = 不限）。

### 2.7 HUD 布局

| 区域 | 内容 |
|---|---|
| 顶部 | 步数 / 剩余目标词数 / 金币 |
| 主目标槽 | 待找词列表（已找到置灰打勾），可显示提示 |
| 额外词汇槽 | 彩蛋词收集格（默认 3 格），集满触发奖励并重置 |
| 底部 | 提示道具按钮（普通 / 定向 / 魔棒）、暂停、重开 |

## 3. 零资源程序化实现 (Zero-Asset Directives)

### 3.1 3D 方块与文本纹理

- 严禁运行时加载 PNG/JPG/TTF/字体 JSON。
- 流程：
  1. 离屏 `Canvas 2D`（建议 256×256）绘制方块底色、圆角、字符、状态装饰。
  2. 使用系统字体 `sans-serif`（中文可加 `"PingFang SC","Microsoft YaHei"` 回退栈）绘制字符并自动缩放适配。
  3. `new THREE.CanvasTexture(canvas)` 赋给 `MeshStandardMaterial.map`。
  4. 状态变化（选中/冰冻/锁链/炸弹倒计时/消除高亮）通过**重绘纹理**或修改材质颜色/自发光实现。
- 性能：按 `char + state` 缓存 `CanvasTexture`，避免重复绘制；方块使用 `InstancedMesh` 或对象池。

### 3.2 障碍方块规则

| 类型 | 字段 | 规则 | 备注 |
|---|---|---|---|
| 普通 | `type:"normal"` | 常规消除 | — |
| 冰冻 | `type:"ice", hp:2` | 首次被匹配：**不消除字符**，仅 `hp-1` 并更新视觉；`hp=0` 时才消除。冰冻期间字符仍可被选中匹配 | 破冰不计额外步 |
| 锁链 | `type:"lock", lockKey:"w2"` | 未解锁时**不可被选中**。当 `lockKey` 指向的目标词被消除后自动解锁；`lockKey` 为空时相邻任一目标词消除即解锁 | 解锁永久 |
| 炸弹 | `type:"bomb", countdown:5` | 每成功消除 1 步 `countdown-1`；归零仍未消除 → 爆炸，**直接判负（已确认）** | — |

- 锁链/炸弹方块**不下落（已确认）**：锁定与炸弹方块固定在原格，其余方块下落。注：冰方块按普通方块处理，可随重力下落。

### 3.3 程序化音频合成

- 全局单例 `AudioContext`，**必须由首次用户手势创建/恢复**（浏览器 Autoplay 策略）。
- 音效合成：
  - 点击：`OscillatorNode` 正弦波 880Hz + 短衰减 `GainNode`（~80ms），模拟木鱼/水滴。
  - 消除：阶梯频率多振荡器，随 combo 递升和谐（默认 C 大调五声：C D E G A）。
  - 失败：低频锯齿波短促下坠。
  - 胜利：上行琶音。
- BGM：`setInterval`/`AudioBufferSourceNode` 循环播放五声调式低音量序列，默认音量 0.25。
- 设置项：`sfx`、`bgm`、`volume` 持久化（见 11.2）。

## 4. 游戏机制细节 (Mechanics)

### 4.1 双盘联动（主目标槽 + 额外词汇槽）

- **主目标槽**：本关全部目标词，命中后打勾置灰，推进通关。
- **额外词汇槽**：拼出 `bonus_dictionary` 中的词则填入彩蛋格，不报错、不消除棋盘、不扣步，并给予少量金币。集满 `bonus_target`（默认 3）格 → 奖励金币/提示道具并清空槽（数值见 10.1）。

### 4.2 多级动态提示

| 提示 | 行为 | 建议成本 |
|---|---|---|
| 普通提示 | 随机选一个未完成目标词，高亮其在当前棋盘上的一格（不自动消除） | 20 金币 |
| 定向提示 | 玩家点击某格 → 高亮包含该格的目标词路径 | 40 金币 |
| 魔棒/火箭 | 自动完成（消除）一个未完成目标词，或随机点亮 3 个字符 | 80 金币 |

- 提示只在**棋盘确实可解**时可用；不可解时应提供魔棒兜底。

## 5. 玩家交互与射线拾取流程 (Interaction Flow)

1. 玩家在屏幕滑动或点击。
2. `Raycaster` 由相机与指针 NDC 坐标构建，与方块 `InstancedMesh`/`Mesh` 求交。
3. 高亮选中方块并播放点击音。
4. 按顺序连线字符，按 2.3 优先级校验。
5. 命中则播放消除动画与和弦、计算重力下落坐标并平滑补位；未命中则播放失败反馈并清空路径。

### 5.1 UX 屏幕流程

`启动(首屏点击解锁音频) → 主菜单 → 关卡选择 → 游戏 → 结算(胜/负) → 返回`

- 主菜单：开始、关卡选择、设置（语言/音效/BGM/音量）、重置进度。
- 结算页：得分、星级、金币、下一关/重玩。
- 暂停：继续、重开、返回、设置。
- 不提供逐步「撤销」（与重力/障碍状态机冲突且易被滥用）；仅提供「重开本关」并二次确认。选中路径在提交前可逐格撤销（见 2.2）。

## 6. 美术风格与 3D 渲染规范 (Art Style & Visual Spec)

### 6.1 风格总纲 ✅

- 全局采用 **低多边形（Low-Poly）+ 莫兰迪（Morandi）+ 马卡龙（Macaron）** 混合风格。
- **低多边形**：所有 3D 几何体使用低面数、`flatShading: true` 平面着色，呈现硬朗刻面；禁止高细分曲面。
- **莫兰迪**：主体色为低饱和、带灰度的柔和色调，营造高级、静谧、禅意氛围。
- **马卡龙**：叠加少量明亮柔和的粉彩色作为点缀，避免整体过于沉闷。
- 该风格适用于**首页、棋盘、方块、UI、粒子、结算界面**，保持全局统一，替代 v6.0 的深色霓虹设定。

## 7. 关卡数据结构规范 — JSON Schema (Level Data Schema)

> v7.0 完整定稿，替代 v6.0 第 4 章模糊描述。

### 7.1 关卡包索引

```json
{
  "schemaVersion": "1.0",
  "packs": [
    { "language": "zh-CN", "levels": "wf_zh" },
    { "language": "en-US", "levels": "wf_en" }
  ]
}
```

### 7.2 单关卡对象

```json
{
  "schemaVersion": "1.0",
  "level_id": "wf_zh_001",
  "language": "zh-CN",
  "theme": "自然风光",
  "difficulty_tier": "tutorial",
  "grid_dim": { "x": 4, "y": 4 },
  "move_limit": null,
  "bonus_target": 3,
  "reward": { "coins": 50, "stars": 3 },
  "initial_board": [
    { "x": 0, "y": 0, "char": "山", "type": "normal" },
    { "x": 1, "y": 0, "char": "水", "type": "ice", "hp": 2 },
    { "x": 2, "y": 1, "char": "云", "type": "lock", "lockKey": "w2" },
    { "x": 3, "y": 2, "char": "火", "type": "bomb", "countdown": 5 }
  ],
  "target_words": [
    {
      "id": "w1",
      "text": "山水",
      "hint_text": "自然景观，山与水的合称",
      "default_path": [{ "x": 0, "y": 0 }, { "x": 1, "y": 0 }],
      "allow_reverse": true
    }
  ],
  "bonus_dictionary": ["云海", "火山"],
  "solution_flow": [
    {
      "step": 1,
      "word_id": "w1",
      "text": "山水",
      "path": [{ "x": 0, "y": 0 }, { "x": 1, "y": 0 }],
      "triggers_gravity": true,
      "combo": 0,
      "board_hash": "a1b2c3"
    }
  ]
}
```

### 7.3 字段定义

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `schemaVersion` | string | 是 | Schema 版本 |
| `level_id` | string | 是 | 唯一标识，如 `wf_zh_001` |
| `language` | string | 是 | `zh-CN` / `en-US` |
| `theme` | string | 是 | 主题标签 |
| `difficulty_tier` | string | 是 | `tutorial`/`easy`/`medium`/`hard` |
| `grid_dim` | `{x:number,y:number}` | 是 | 棋盘列/行 |
| `move_limit` | number \| null | 否 | 步数上限，null 不限 |
| `bonus_target` | number | 否 | 彩蛋槽容量，默认 3 |
| `reward` | object | 否 | 首通奖励 |
| `initial_board` | Tile[] | 是 | 方块列表（含坐标与障碍元数据） |
| `target_words` | TargetWord[] | 是 | 主目标词 |
| `bonus_dictionary` | string[] | 否 | 本关合法彩蛋词 |
| `solution_flow` | SolutionStep[] | 是 | 标准解序列，供验证与提示 |

**Tile**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `x`, `y` | int | 是 | 坐标 |
| `char` | string | 是 | 单字符 |
| `type` | enum | 是 | `normal`/`ice`/`lock`/`bomb` |
| `hp` | int | ice 必填 | 冰冻耐久，默认 2 |
| `lockKey` | string \| null | lock 必填 | 解锁所需目标词 id |
| `countdown` | int | bomb 必填 | 倒计时步数，默认 5 |

**TargetWord**

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | 唯一，如 `w1` |
| `text` | string | 是 | 词汇文本 |
| `hint_text` | string | 是 | 提示文案 |
| `default_path` | `{x,y}[]` | 否 | 初始路径（生成时给出，用于提示/校验） |
| `allow_reverse` | bool | 否 | 是否允许反向，默认 true |

## 8. 关卡生成器算法 (Level Generator)

> v7.0 新增。生成器为**离线 Node 脚本**，产物内嵌进应用。运行时零请求。

### 8.1 工具

- `tools/generate-levels.mjs`
- 输入：主题词库、难度参数表、随机种子。
- 输出：`wf_zh.json` / `wf_en.json` + 校验报告。

### 8.2 生成流程

1. 按难度选取 `grid_dim` 与目标词数量（见第 9 章）。
2. **摆放目标词**：对每个目标词，在当前棋盘可用格中，从随机起点沿 8 邻域（或约束方向）贪心/回溯生成一条可用路径，写入方块。
3. **填充剩余格**：从字库/字母表按主题权重随机填字，避免意外形成未登记的目标词。
4. **生成彩蛋词**：扫描棋盘可形成的合法词组（对照词典），剔除目标词后取前 N 个作为 `bonus_dictionary`。
5. **模拟解法**：按目标词消除顺序逐步模拟：消除 → 重力下落 → 记录 `solution_flow` 与 `board_hash`。
6. **可解性校验**：每步消除后，**剩余每个目标词在当前棋盘上仍存在一条合法相邻路径**；否则回溯调整顺序/摆放，或重生成。
7. **障碍注入**：在保证可解的前提下，将指定数量的方块升级为冰/锁/炸弹，并校正 `hp/countdown/lockKey`。

### 8.3 可解性断言（生成器必须通过）

- 初始棋盘：所有目标词均可形成。
- `solution_flow` 每一步执行后，剩余目标词均可形成。
- 不存在「目标词方块被其它词消除而永久消失」的死局。
- `move_limit`（如有）≥ `solution_flow.length` 且留有余量。

### 8.4 随机可复现

- 每关记录 `seed`，相同 seed 生成相同关卡，便于回归测试。

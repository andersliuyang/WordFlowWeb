# WordFlow (字.迷) - 3D 纯静态消除填字游戏开发设计与执行规范 (v6.0)

## 1. 项目概述与核心架构 (Overview & Architecture)

**WordFlow (字.迷)** 是一款基于 Web 技术构建的 3D 混合式消除填字游戏。项目采用**零外部静态资源（Zero-HTTP Assets）**架构，所有 3D 视觉元素、字符纹理、音效及关卡内容均通过代码算法与纯前端能力程序化生成，支持部署为单文件静态网页。

### 1.1 核心技术选型

- **宿主环境**：纯静态 HTML5 / 单文件 Web 应用（支持 CDN、Vercel、GitHub Pages 部署）。
- **3D 视觉引擎**：**Three.js (WebGL)**，负责 3D 空间、立方体网格、摄像机视角及射线拾取交互。
- **动态纹理生成器**：**HTML5 Canvas 2D API**，负责在内存中实时绘制文本并转换为 3D 材质贴图。
- **程序化音频引擎**：**Web Audio API**，负责通过合成器算法实时生成点击、消除及背景音乐反馈。
- **数据存储**：AI 预生成的离线 JSON 关卡库，打入静态资源包中。

## 2. 零资源程序化实现指引 (Zero-Asset Directives)

### 2.1 3D 方块与文本纹理生成指引

- **实现原理**：严禁加载外部图片（PNG/JPG）或 3D 字体文件（JSON/TTF）。
- **开发指引**：
  1. 创建一个隐式离屏 Canvas 2D 容器。
  2. 使用系统的默认无衬线字体（Sans-serif）在 Canvas 上绘制背景块与字符（英文字母或汉字）。
  3. 将渲染完成的 Canvas 作为材质纹理（CanvasTexture）赋予 Three.js 的 3D 立方体几何网格（BoxGeometry）。
  4. 状态变更（如选中、冰冻/锁链特效、消除高亮）时，通过重新绘制 Canvas 纹理或修改材质颜色属性实现，无需加载新资源。

### 2.2 程序化音频合成指引

- **实现原理**：严禁加载外部音频文件（MP3/WAV/OGG）。
- **开发指引**：
  1. 初始化全局 Web Audio 上下文（AudioContext）。
  2. **点击/选中音效**：使用振荡器（OscillatorNode）生成高频正弦波，辅以极短的衰减包络（GainNode），模拟水滴或木鱼点击声。
  3. **消除/连击音效**：按阶梯频率连贯触发多个振荡器，根据 Combo 连击层级播放逐级上升的和弦音阶。
  4. **背景音乐 (BGM)**：使用定时器循环播放低音量的频率序列（如 Zen 风格的五声调式），全由代码实时演算。

## 3. 游戏机制与爆款特性抽象逻辑 (Core Gameplay & Mechanics)

### 3.1 逻辑抽象规则

- **符号节点 (Tile Node)**：英文模式下为单个字母 (A-Z)，中文模式下为单个常用汉字 (3500字库)。
- **逻辑匹配单元**：英文模式下为单词，中文模式下为成语或常用词组。
- **3D 视觉呈现**：表面带有对应贴图的悬浮 3D 立方体网格。
- **重力物理下落**：下方方块被消除后，上方方块平滑补位下落。

### 3.2 爆款核心玩法特性 (Mainstream Mechanics)

1. **双盘联动机制（主目标槽 + 额外词汇槽 Bonus Words）**：
   - **主目标网格**：消除后可推进关卡进度，清空即可通关。
   - **额外词汇槽**：拼出合法但不在主网格内的单词/词组时，不报错，而是存入“彩蛋槽”。积满指定数量后可换取金币或道具奖励，降低玩家试错挫败感。
2. **障碍方块机制 (Obstacle Tiles)**：
   - **冰冻方块 (Ice Tile)**：字符需被成功拼对并消除 2 次才能彻底清空。
   - **锁链方块 (Lock Tile)**：需先消除与其相邻的特定单词方可解锁。
   - **炸弹方块 (Bomb Tile)**：带有倒计时步数（如 5 步），需在步数归零前将其消除。
3. **多级动态提示系统 (Multi-tier Hint System)**：
   - **普通提示**：随机高亮并填充主网格中某个未解单词的首字符。
   - **定向提示**：玩家指定点击主网格空槽，定向填充该位置字符。
   - **魔棒/火箭提示**：随机清除/点亮 3 个未解字符（应对死局）。
4. **连击与心流反馈 (Combo System)**：
   - 在 3 秒内连续拼对单词，或下落重力触发二次自动消除时触发 Combo。
   - 触发时通过 Web Audio 播放递升和弦，并伴随 3D 粒子爆炸反馈。

### 3.3 玩家交互与射线拾取流程

1. 玩家在屏幕上滑动或点击。
2. 利用 Three.js 射线投射器（Raycaster）检测鼠标/触控点在 3D 空间中相交的方块 Mesh。
3. 高亮选中方块，并触发 Web Audio 实时合成的点击提示音。
4. 按顺序连线选中的字符序列，优先校验主目标网格；若未命中则校验额外词库（Bonus Words）。
5. 校验成功则触发消除动画与和弦音效，计算上方方块的重力下落坐标并执行平滑补位动画。

## 4. AI 预生成关卡数据结构规范 (AI Level Pre-generation Spec)

关卡谜题由 AI 离线批量预生成，打成纯静态 JSON 数据，无需运行时请求任何后端 API。

### 4.1 JSON 字段定义规范

- **level_id** (String)：关卡唯一标识符（如 `wf_zh_001`）。
- **language** (String)：关卡语言代码（`zh-CN` 或 `en-US`）。
- **theme** (String)：关卡主题（如“自然风光”）。
- **difficulty_tier** (String)：难度梯度（`tutorial` / `easy` / `medium` / `hard`）。
- **grid_dim** (Object)：3D 矩阵棋盘规格（如 `{"x": 4, "y": 4}`）。
- **initial_board** (Array)：二维字符矩阵（包含字符类型，如普通字块、冰冻块、锁链块）。
- **target_words** (Array)：主目标词组列表，包含词汇文本、提示文本及初始坐标。
- **bonus_dictionary** (Array)：该关卡允许触发“额外词汇槽”的合法备选词库。
- **solution_flow** (Array)：标准解题步骤列表，包含步骤编号、待消除词汇、消除坐标以及是否触发重力下落标识。

## 5. 关卡难度平缓曲线 (Difficulty Progression)

- **第 1 - 10 关（新手引导期）**：无障碍方块，字符少（3x3），仅需 2~3 次消除，主打极速通关建立自信。
- **第 11 - 50 关（成长期）**：棋盘扩大至 4x4，解锁额外词汇槽（Bonus Words）与 Combo 连击机制。
- **第 50+ 关（挑战期）**：引入冰冻、锁链及炸弹障碍方块，结合步数限制，提高策略挑战性。

## 6. AI 工程师/AI Agent 执行路线图 (Execution Roadmap)

1. **步骤一：搭建零资源 3D 渲染环境**
   配置 Three.js 基础场景（Scene, Camera, Renderer），编写基于 Canvas 2D 的动态贴图生成逻辑，实现包含冰冻/锁链等特殊状态的 3D 立方体渲染。
2. **步骤二：搭建程序化音频引擎**
   基于 Web Audio API 编写音频合成模块，配置振荡器与增益节点，提供点击、消除、Combo 连击和弦及胜利场景的实时音效函数。
3. **步骤三：实现消除、障碍与重力物理逻辑**
   实现 3D 空间射线拾取（Raycaster）、双盘（主网格+额外词汇槽）字符校验、障碍方块状态切换、提示道具逻辑以及沿坐标轴平滑下落补位（Tween 动画）。
4. **步骤四：装载 AI 关卡库并打包**
   解析包含难度梯度与障碍设置的静态 JSON 关卡数据，实现中英文模式切换与进度存储，合并导出为单文件静态应用。
